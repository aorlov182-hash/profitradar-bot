# ProfitRadar MP — Refactoring Plan v1

Дата: 26.07.2026

## Цель

Подготовить проект ProfitRadar MP к стабильному коммерческому запуску.

Главные задачи:

- сохранить работоспособность текущего MVP
- улучшить архитектуру
- подготовить масштабирование
- подготовить переход к PostgreSQL
- повысить безопасность


# Этап 1. Аудит

Статус: START

Проверить:

- структуру проекта
- зависимости
- конфигурацию
- базу данных
- обработчики Telegram
- сервисный слой


# Этап 2. Configuration

Цели:

- создать .env.example
- убрать жёстко заданные значения
- унифицировать настройки


# Этап 3. Database

Текущее:

SQLite

План:

SQLite → PostgreSQL

Добавить:

- SQLAlchemy
- Alembic migrations
- Repository layer


# Этап 4. Architecture

Улучшить:

- разделение ответственности
- сервисы
- модели
- обработчики


# Этап 5. Security

Проверить:

- BOT_TOKEN
- API ключи WB/Ozon
- webhook
- admin access


# Этап 6. Testing

Добавить:

- unit tests
- проверки калькулятора
- тесты базы данных


# Этап 7. Production Ready

Подготовить:

- Docker
- Render deployment
- logging
- monitoring


## Правила

1. Не ломать работающий MVP.
2. Все изменения делать маленькими коммитами.
3. После каждого этапа проверять запуск бота.
