# ADR-001 — Использование Render для размещения проекта

Дата:

26.07.2026

Статус:

Accepted


# Контекст

ProfitRadar MP должен работать постоянно без зависимости от домашнего компьютера разработчика.

Telegram-бот должен быть доступен пользователям 24/7.


# Рассмотренные варианты

## Локальный компьютер

Плюсы:

- полный контроль;
- бесплатно.

Минусы:

- компьютер должен быть постоянно включен;
- нестабильность;
- невозможность масштабирования.


## VPS сервер

Плюсы:

- полный контроль;
- высокая гибкость.

Минусы:

- требуется настройка сервера;
- требуется обслуживание;
- дополнительные расходы.


## Render

Плюсы:

- простой deployment;
- автоматический запуск;
- интеграция с GitHub;
- подходит для MVP;
- минимальное обслуживание.


# Решение

Использовать Render как основной сервер размещения MVP версии ProfitRadar MP.


# Последствия

Положительные:

- быстрый запуск;
- простое обновление через GitHub;
- стабильная работа webhook;
- минимальная инфраструктура.


Отрицательные:

- ограничения бесплатного тарифа;
- зависимость от внешнего сервиса.


# Обоснование

На этапе MVP важнее скорость разработки и стабильность продукта, чем максимальный контроль инфраструктуры.
