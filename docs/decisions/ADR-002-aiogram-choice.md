# ADR-002 — Использование aiogram для Telegram-бота

Дата:

26.07.2026

Статус:

Accepted


# Контекст

ProfitRadar MP использует Telegram-бота как основной пользовательский интерфейс MVP.

Необходимо было выбрать надежный Python-фреймворк для создания Telegram-бота с возможностью дальнейшего развития.


# Рассмотренные варианты


## python-telegram-bot

Плюсы:

- популярный фреймворк;
- хорошая документация;
- большое сообщество.

Минусы:

- менее удобен для сложных асинхронных сценариев.


## Telebot

Плюсы:

- простой старт;
- подходит для небольших ботов.

Минусы:

- хуже подходит для масштабируемых проектов.


## aiogram

Плюсы:

- современная асинхронная архитектура;
- высокая производительность;
- удобная работа с Telegram API;
- хорошо подходит для сложных сценариев;
- активно развивается.


# Решение

Использовать aiogram как основной Telegram-фреймворк ProfitRadar MP.


# Последствия


Положительные:

- высокая скорость обработки запросов;
- удобная работа с webhook;
- возможность масштабирования;
- хорошая интеграция с FastAPI.


Отрицательные:

- требуется понимание async/await;
- немного сложнее для новичков.


# Обоснование

ProfitRadar MP планируется развивать от простого калькулятора прибыли до полноценной платформы аналитики.

Поэтому выбран фреймворк, который подходит не только для MVP, но и для дальнейшего роста продукта.
