# ProfitRadar MP — Монетизация

## Цель

Монетизация ProfitRadar MP строится по модели подписки (SaaS).

Основная задача — предоставить полезный бесплатный функционал и предложить пользователю перейти на PRO для получения расширенных возможностей.

---

# Принципы

Монетизация не должна мешать пользоваться продуктом.

Пользователь должен сначала получить ценность, а затем принять решение о покупке подписки.

Мы не ограничиваем работу искусственно. Ограничения касаются только расширенных функций.

---

# Тарифы

## FREE

Бесплатный тариф предназначен для знакомства с системой.

Доступно:

- расчет прибыли;
- расчет маржи;
- ручной ввод данных;
- базовая аналитика;
- Telegram-бот;
- Android-приложение;
- обновления приложения.

---

## PRO

Рекомендуемая стоимость:

- 490 ₽/месяц (стартовая цена);
- в дальнейшем — 990 ₽/месяц.

В тариф входят:

- подключение API Wildberries;
- подключение API Ozon;
- автоматическая загрузка данных;
- история расчетов;
- облачная синхронизация;
- ежедневные отчеты;
- уведомления;
- AI-анализ прибыли;
- рекомендации по увеличению прибыли;
- прогнозирование прибыли;
- приоритетная поддержка.

---

# Подписка

Подписка действует ограниченный период.

После окончания:

- функции FREE продолжают работать;
- функции PRO автоматически отключаются;
- данные пользователя сохраняются.

После повторной оплаты все функции вновь становятся доступными.

---

# Способы оплаты

Планируется поддержка:

- банковских карт;
- СБП;
- ЮMoney;
- российских платежных агрегаторов.

В будущем возможно добавление:

- Google Play Billing;
- RuStore Pay;
- AppGallery;
- других локальных способов оплаты.

---

# Проверка подписки

Проверка статуса выполняется через Backend API.

Telegram-бот, Android-приложение и сайт используют единый механизм проверки.

Статус подписки хранится централизованно.

---

# Авторизация

Авторизация выполняется через Telegram.

Пользователь не создает отдельный логин и пароль.

После подтверждения личности Backend выдает JWT-токены для доступа к API.

Это позволяет использовать одну учетную запись на всех устройствах.

---

# Бесплатный период

После запуска коммерческой версии возможно предоставление пробного периода.

Предварительный вариант:

- 7 дней PRO;
или
- 14 дней PRO.

После окончания пользователь автоматически переводится на тариф FREE.

# Корпоративный тариф

Для агентств и крупных продавцов планируется отдельный тариф.

Возможности:

- несколько сотрудников;
- несколько магазинов;
- расширенные отчеты;
- централизованное управление;
- персональная поддержка.

---

# Принципы развития

Каждая новая функция относится к одной из категорий:

FREE — базовые функции, необходимые каждому пользователю.

PRO — функции, значительно экономящие время и повышающие эффективность работы.

Новые возможности не должны ухудшать опыт пользователей FREE.

---

# Долгосрочная цель

Создать устойчивую модель регулярной подписки, при которой пользователь оплачивает сервис благодаря реальной экономии времени и увеличению прибыли, а не из-за искусственных ограничений.

Основным источником дохода проекта должна стать подписка PRO.
