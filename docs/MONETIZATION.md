# ProfitRadar MP — Монетизация


## Назначение


ProfitRadar MP развивается как коммерческий SaaS-сервис для продавцов Wildberries и Ozon.


Главная модель:

Freemium


Пользователь получает базовые функции бесплатно и может перейти на расширенный PRO-тариф.

# Тарифная модель


## FREE


Цена:

0 ₽


Назначение:

Знакомство пользователя с продуктом.


Возможности:


- расчет прибыли;
- ручной ввод данных;
- расчет маржи;
- базовая история расчетов.


Ограничения:

- нет расширенных отчетов.

# Метрики продукта


Основные показатели:


## MAU

Количество активных пользователей.


## Conversion Rate

Процент перехода FREE → PRO.


## MRR

Ежемесячная повторяющаяся выручка.


## Churn Rate

Количество пользователей, которые отменили подписку.

# Принципы монетизации


Проект придерживается правил:


- сначала ценность, потом продажа;
- бесплатная версия должна быть полезной;
- PRO должен экономить пользователю больше денег, чем стоит;
- отсутствие скрытых платежей.
