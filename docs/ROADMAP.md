# ProfitRadar MP — Дорожная карта

## Общая цель

Преобразовать существующий Telegram-бот в единую платформу для управления прибылью продавцов Wildberries и Ozon.

Конечная архитектура включает:

- Telegram Bot
- Android App
- Backend API
- PostgreSQL
- Website
- AI Analytics

# Принцип разработки

Каждый этап должен завершаться полностью рабочей версией системы.

Не допускается длительная разработка без возможности использования продукта.

После завершения каждого этапа:

- проводится тестирование;
- обновляется документация;
- создаётся Git-коммит;
- выполняется деплой на Render.

---

# Основной принцип проекта

Сначала — стабильность.

Потом — новые функции.

Ни одна новая возможность не должна ухудшать работу уже существующего продукта.
