# Миссия

ProfitRadar MP — это единая платформа для продавцов Wildberries и Ozon, позволяющая видеть реальную прибыль бизнеса, а не только оборот.

Наша цель — сделать финансовую аналитику маркетплейсов простой, понятной, быстрой и доступной каждому селлеру.

---

# Видение проекта

ProfitRadar MP развивается как единая экосистема, включающая:

- Telegram Bot
- Android App
- Backend API
- Web Application
- AI-модуль аналитики

Все продукты используют единый сервер, единую базу данных и общую бизнес-логику.

Пользователь может начать работу с любого устройства и продолжить её на другом без потери данных.

---

# Проблема

Большинство продавцов маркетплейсов знают только оборот.

При этом они не знают:

- сколько реально зарабатывают;
- какие товары работают в плюс;
- какие товары продаются в убыток;
- сколько денег забирают комиссии;
- сколько съедает логистика;
- сколько теряется на возвратах;
- как меняется прибыль каждый день.

Из-за этого многие решения принимаются практически вслепую.

---

# Решение

ProfitRadar MP объединяет все необходимые инструменты в одной системе.

Сегодня доступны:

- Telegram Bot
- Android-приложение

В дальнейшем появятся:

- Backend API
- Web-кабинет
- AI-анализ
- автоматическая синхронизация
- интеграция через API Wildberries
- интеграция через API Ozon

# Основные принципы проекта

При разработке соблюдаются следующие правила.

## Простота

Минимум действий пользователя.

## Скорость

Любое действие должно занимать считанные секунды.

## Надёжность

Все данные безопасно сохраняются.

## Масштабируемость

Архитектура должна позволять развивать сервис без полной переработки.

## Единая экосистема

Все продукты используют единый Backend API.

## Безопасность

Персональные данные и API-ключи пользователей защищаются современными методами шифрования.
