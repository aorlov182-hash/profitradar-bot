# ProfitRadar MP

## Контроль реальной прибыли продавцов маркетплейсов

ProfitRadar MP — это платформа аналитики прибыли для продавцов Wildberries и Ozon.

Главная задача проекта — показать продавцу не просто оборот, а настоящую прибыль после учета всех расходов:

- комиссии маркетплейса;
- логистика;
- возвраты;
- себестоимость товара;
- дополнительные расходы.

# Основная проблема

Большинство селлеров видят:

- количество продаж;
- оборот;
- количество заказов.

Но не видят:

- реальную прибыль;
- убыточные товары;
- влияние комиссий;
- стоимость возвратов;
- фактическую маржинальность.

Из-за этого бизнес может выглядеть успешным, хотя фактически приносит мало прибыли или работает в минус.

---

# Решение

ProfitRadar MP помогает продавцам:

- быстро рассчитывать прибыль товара;
- понимать реальную маржу;
- принимать решения на основе цифр;
- находить проблемные товары.
