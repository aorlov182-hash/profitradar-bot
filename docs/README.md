# ProfitRadar MP

## О проекте

ProfitRadar MP — это экосистема сервисов для продавцов Wildberries и Ozon.

Проект состоит из нескольких взаимосвязанных компонентов:

- Telegram-бот
- Android-приложение
- Backend API
- Веб-сайт
- База данных PostgreSQL
- AI-модуль аналитики

Главная цель проекта — предоставить селлерам простой инструмент для контроля прибыли, расчёта маржинальности и автоматизации аналитики.
