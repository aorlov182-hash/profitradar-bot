# ProfitRadar MP — Технологический стек

## Назначение документа

Этот документ фиксирует используемые технологии, версии и технические стандарты проекта.

Любое изменение технологического стека должно быть согласовано и отражено в данном файле.

---

# Общая архитектура

ProfitRadar MP строится как многокомпонентная система.

Основные компоненты:

```
                    Пользователь

                         |
        --------------------------------
        |              |               |
   Telegram Bot   Android App      Website

        \              |              /

              Backend API

                    |

             PostgreSQL Database

                    |

          External Services

     WB API / Ozon API / Payment / AI
```

# Стиль разработки

Основные правила:

- простой читаемый код;
- минимизация дублирования;

# Итог

ProfitRadar MP строится как современный SaaS-продукт с разделением ответственности:

Telegram и Android — интерфейсы пользователя.

Backend API — бизнес-логика.

PostgreSQL — хранение данных.

AI и внешние API — расширение возможностей системы.

Такая архитектура позволяет развивать продукт без переписывания всей системы.
