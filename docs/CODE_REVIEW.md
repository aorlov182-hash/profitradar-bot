# ProfitRadar MP — Code Review

Дата: 26.07.2026

## 1. Текущее состояние

Проект представляет собой Telegram-бота для контроля прибыли продавцов маркетплейсов Wildberries и Ozon.

Статус:
- Telegram бот работает
- Развертывание Render успешно
- Webhook настроен
- Калькулятор маржи работает
- SQLite используется как текущая база данных
- Архитектура подготовлена к дальнейшему развитию


## 2. Технологический стек

Backend:
- Python
- aiogram 3
- FastAPI webhook
- APScheduler

Database:
- SQLite (текущая)
- PostgreSQL (планируется)

Deployment:
- Render

Frontend:
- Telegram Bot
- Landing page


## 3. Найденные проблемы


### 3.1 База данных

Текущее состояние:
SQLite

Проблемы:
- ограниченная масштабируемость
- возможны проблемы при нескольких пользователях
- нет полноценной миграции схем


Решение:
Переход на PostgreSQL.


---

### 3.2 Архитектура

Плюсы:

- разделение handlers/services/models
- отдельный config
- отдельные middleware


Проблемы:

- требуется улучшение dependency injection
- требуется единый слой работы с БД


---

### 3.3 Безопасность

Проверить:

- хранение BOT_TOKEN
- шифрование API ключей WB/Ozon
- права администратора
- защиту webhook


---

### 3.4 Код

Требуется:

- убрать дублирование
- добавить type hints
- добавить обработку ошибок
- добавить logging


---
