# ProfitRadar MP — Авторизация и безопасность


## Назначение

Система авторизации ProfitRadar MP отвечает за:

- идентификацию пользователей;
- защиту данных;
- управление доступом;
- работу подписок;
- безопасность API.


Основные принципы:

- простой вход;
- безопасность;
- минимальное количество действий пользователя;
- поддержка нескольких устройств.


---

# Способы авторизации


В системе предусмотрены:


## 1. Telegram Login

Основной способ входа.


Используется для:

- Telegram Bot;
- Android приложения;
- быстрого доступа.


Преимущества:

- не нужен пароль;
- быстрый вход;
- подтверждение личности через Telegram.


---

## 2. Email + пароль

Дополнительный способ.


Используется для:

- Website;
- личного кабинета;
- корпоративных клиентов.


Пароли:

- не хранятся напрямую;
- сохраняются только в виде хеша.

# JWT система


Используются два типа токенов:


## Access Token


Назначение:

Кратковременный доступ к API.


Срок жизни:

15-60 минут.


Используется:

каждый API запрос.



---

## Refresh Token


Назначение:

Обновление Access Token.


Срок жизни:

30 дней.


Хранение:

защищенное хранилище устройства.


---

# Процесс входа через Telegram


Шаги:


1. Пользователь открывает приложение.


2. Нажимает:

"Войти через Telegram"


3. Приложение передает данные Telegram.


4. Backend проверяет пользователя.


5. Создается аккаунт или выполняется вход.


6. Backend возвращает JWT токены.


7. Пользователь получает доступ.

# Защита данных


## Пароли


Используется:


- bcrypt;
- salt.


Никогда:

- не хранятся открытые пароли.



---

## API ключи маркетплейсов


Ключи WB/Ozon:


- шифруются перед сохранением;
- доступны только владельцу;
- не передаются другим пользователям.

3. Пользовательские права.


4. Активность подписки.
