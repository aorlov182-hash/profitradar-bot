# ProfitRadar MP — Архитектура проекта

## Общая концепция

ProfitRadar MP — это масштабируемая SaaS-платформа для продавцов Wildberries и Ozon.

Архитектура строится по принципу разделения компонентов:

- пользовательские интерфейсы;
- серверная логика;
- база данных;
- внешние интеграции;
- AI-модули.

Главная цель архитектуры — возможность постепенно расширять проект без переписывания существующего кода.

# Компоненты системы

## 1. Telegram Bot

### Назначение

Основной быстрый инструмент взаимодействия пользователя с сервисом.

### Технологии

- Python
- aiogram 3.x

### Функции

Текущие:

- расчет прибыли;
- расчет маржинальности;
- быстрый ввод данных.

Будущие:

- уведомления;
- ежедневные отчеты;
- AI-рекомендации;
- управление подпиской.

---

# 2. Backend API

## Назначение

Центральный сервер проекта.

Все приложения работают через Backend API.

## Технологии

- Python
- FastAPI
- SQLAlchemy
- Alembic

## Функции

Backend отвечает за:

- пользователей;
- авторизацию;
- расчеты;
- подписки;
- платежи;
- хранение данных;
- интеграции.

# Авторизация

Основной вариант:

Telegram Login


Процесс:

1. Пользователь открывает приложение.
2. Приложение связывается с Telegram.
3. Telegram подтверждает пользователя.
4. Backend создает JWT токены.
5. Пользователь получает доступ.
